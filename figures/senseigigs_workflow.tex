% Senseigigs — system workflow figure, research-paper style.

%
% SCOPE: this figure shows ONLY the ~0.89 NDCG design — two stages, retrieval then
% LambdaMART re-ranking. The tier-1 ensemble, the cross-encoder and the weighted
% fusion are deliberately NOT drawn; they belong to the 0.91 variant.
%
% WHY THIS IS NOT "A ROW OF BOXES": concrete data is drawn at every hop — the real
% gig text, real provider-id pills for each ranked list, a real feature vector for
% one example pair, real scored output rows.
%
% LAYOUT DISCIPLINE - three defects that are invisible in source and ruin the render:
%   1. A container tint is OPAQUE (`retC!4` = 4% colour + 96% WHITE, not 4% alpha).
%      Containers are declared after their contents (their `fit=` list needs those
%      nodes), so they paint over every pill and cell. They MUST sit on the
%      background layer - see the pgfonlayer blocks below.
%   2. Every box style sets an explicit `text width`. Without it a box sizes to its
%      content and sprawls into the neighbouring column.
%   3. Each stage owns a fixed x-band, separated by a gutter.
% verify with: python check_layout.py
